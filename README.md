# CAN-Based Industrial Safety Monitoring System Using Dual STM32 Nodes

## Project Overview

This project presents a CAN-Based Industrial Safety Monitoring System using Dual STM32F407 Nodes, CAN Communication, ESP32, MQTT, and a Flask Web Dashboard. The system monitors machine vibration, temperature, and humidity, exchanges sensor data over the CAN bus, and provides both local and remote monitoring through MQTT and a web-based dashboard.
